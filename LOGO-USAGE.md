# Logo placement in Website v3

- Navbar: `assets/brand/amanah-logo-horizontal.svg`
- Browser favicon: `assets/brand/amanah-mark-favicon.svg`
- Hero: no repeated full logo; the Amanah mark is integrated into the trust-passport illustration.
- Footer: text-only company identity to avoid visual repetition.
- Dark backgrounds: use `amanah-logo-horizontal-white.svg` if adding a full logo.
- App link cards or mobile install prompts: use `amanah-mark-primary.svg`.

## Final naming consistency

Branded labels use:

- Urdu: `أمانة`
- English: `Amanah`

Examples:

- `أمانة: پاکستان کا قابلِ اعتماد خدماتی نیٹ ورک`
- `أمانة خدمات`
- `أمانة تصدیقی کارڈ`
- `أمانة ڈیجیٹل کے بارے میں`
- `Amanah: Pakistan's trusted workforce network`
- `Amanah Services`
