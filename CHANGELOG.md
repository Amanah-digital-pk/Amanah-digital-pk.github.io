# Changelog

Notable changes to the Amanah Digital website are documented here.

## v4.6 — Vision and live-app integration

- Added a dedicated bilingual public Vision page without exposing confidential investor or implementation details.
- Connected the Vision page to the live Amanah public prototype.
- Added language-query support so links from the app open the website in the current Urdu or English language.
- Removed unnecessary terminal punctuation from the Urdu About-page headline.
- Centred Privacy and Terms links in the smartphone footer while preserving the desktop layout.
- Updated repository documentation to identify the application as live rather than planned.

## v4.5 — Mobile header correction

- Kept the established desktop layout unchanged.
- Positioned the Urdu mobile menu button on the left and the logo on the right.
- Kept the English mobile logo on the left and menu button on the right.
- Made the Urdu/English language switch visible at the top of the opened mobile menu.

## v4.4 — Final layout corrections

- Selected the correct language-specific logo before first paint.
- Removed the initial English-logo flash in Urdu mode.
- Disabled Quarto page-grid side columns.
- Centred and widened the main canvas to a maximum width of 1600 px.
- Preserved the header and navigation ordering introduced in v4.3.

## v4.3 — Definitive bilingual layout

- Replaced Quarto's generated navbar with a custom bilingual header.
- Eliminated duplicate-logo generation.
- Applied equal left and right gutters with a centred 1500 px canvas.
- Added a controlled smartphone and tablet hamburger menu.

## v3.7 — Naming consistency

- Standardised prominent branded labels:
  - Urdu: `أمانة`
  - English: `Amanah`
- Retained concise navigation labels for usability.

## v3.6 — Urdu logo correction

- Corrected the Urdu logo lockup.
- Positioned the brand mark on the right.
- Used large `أمانة` lettering with smaller `ڈیجیٹل` beneath it.

## v3.4 — Bilingual and accessibility improvements

- Added compact English and Urdu navbar logos with tighter SVG view boxes.
- Updated Urdu brand rendering.
- Improved respectful Urdu terminology.
- Expanded digital-support wording to include smartphones, bank accounts, Easypaisa, and JazzCash.
- Removed the Urdu-to-English flash on Privacy and Terms pages.
- Increased visible logo size across desktop, tablet, and mobile.

## v3.3 — Trust, policy, and worker-support improvements

- Stabilised the bilingual footer across desktop and mobile.
- Added complete bilingual Privacy and Terms pages.
- Clarified identity verification, data use, fees, complaints, safety, and account restrictions.
- Added a worker-first model for people with limited digital work history, literacy, or smartphone experience.
- Added assisted onboarding, voice and visual guidance, transparent training, staged trust building, and accountability for households and professionals.
