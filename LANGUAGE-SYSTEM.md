# Urdu-first language system v3.2

- Urdu opens by default and English is available from the prominent language control.
- Each version is complete: English content does not appear inside Urdu sentences.
- Brand name `Amanah` remains in Roman script.
- Familiar occupations are written in common Urdu spellings, such as الیکٹریشن، پلمبر، ڈرائیور and بیوٹیشن.
- Technical concepts use simple Urdu:
  - onboarding → ابتدائی اندراج
  - verification → تصدیق / جانچ
  - profile → تعارف
  - work history → کام کا ریکارڈ
  - live selfie → اسی وقت لی گئی اپنی تصویر
  - trust score → اعتماد نمبر
- Noto Sans Arabic is used throughout the Urdu interface because it is clearer for low-literacy and older users and is more stable across browsers and PDF rendering than large Nastaliq headings.
